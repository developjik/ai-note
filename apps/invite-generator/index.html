팀 초대장 만들기

팀 관리자가 새 팀원에게 줄 초대장을 만드는 페이지예요. 이 페이지는 브라우저 안에서만 작동하고 입력한 정보는 어디로도 전송되지 않아요.

GitHub → Settings → Developer settings → Personal access tokens (classic) → repo 권한만 선택해 만들어 주세요. 팀원 각자 자기 토큰을 넣어야 해요.

첫 실행 때 앱이 이 이름으로 비공개 저장소를 자동으로 만들어요.

초대장 문자열과 암호는 각각 따로 전달해 주세요(메시지·구두 등).

알림: 초대장에는 위 토큰이 암호화되어 담깁니다. 암호는 충분히 길게 만들고, 한 번 쓴 토큰는 필요 없어지면 GitHub 설정에서 폐기해 주세요.
